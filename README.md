# Bozo Lay Tracker

A mobile-first React and Blueprint frontend for recording the group’s weekly picks.

Run `npm ci` and `npm run dev`. Run `npm run build` to generate `dist/`.

The frontend preview stores picks in the current browser and demonstrates a Monday-start week, a Saturday noon Eastern deadline, and a rotation beginning with Jack. It has no sign-in or reminder flow. Shared Supabase persistence and the production schedule are pending.
